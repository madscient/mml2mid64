# 03. マクロ

> 完成度: 2 方式とも実測で確認済み。`[?]` が 4 件。

行頭が `$` の行はマクロ定義行です。2 つの方式があり、**展開される段階が違うため
挙動も違います。**

| 方式 | 記法 | 展開の段階 | 出典 |
| --- | --- | --- | --- |
| 旧方式 | `$a` 〜 `$z`, `$0a` 〜 `$9z` | コマンド解釈時 | `[doc]` |
| 長い名前 | `${名前}`, `${名前:引数,…}` | 行の前処理時（テキスト置換） | `[fork]` |

`${a}` のように旧方式と同じ形の名前（英小文字 1 字、または数字 1 字＋英小文字 1 字）を
波括弧で書いた場合は、**旧方式のマクロと同じものを指します。** `$0a` で定義して
`${0a}` で呼ぶ（またはその逆）ことができます。`[fork]` `[obs]`

## 3.1 旧方式 `$a`

### 定義

```
$a  c8cc
$1a k100 J36
```

- 名前は `[0-9]?[a-z]` の 1〜2 文字。`$0a` は `$a` と同じものです。`[doc]`
- 全部で 260 個（`$a`〜`$z` と `$0a`〜`$9z`。`$0x` 系は `$x` 系と同一）。`[doc]`
- 同じ名前を 2 度定義した場合、**後の定義が有効**になります。`[obs]`

### 呼び出し

MML 行の中に `$a` と書きます。

- **定義はファイル中のどこにあってもかまいません。** 呼び出しより後ろでも
  有効です。`[doc]` `[obs]`
- **ただしマクロの中から別のマクロを呼ぶ場合だけは、呼ばれる側を先に定義して
  おく必要があります。** そうでないと `undefined macro call '$?' (in macro)` で
  停止します。`[doc]` `[obs]`

### ループは定義時に展開される

**旧方式のマクロ本体に書いた `[ ]` ループは、呼び出し時ではなく定義時に
展開されます。** したがってループはマクロ内で閉じていなければならず、
呼び出し側に回数を書くことはできません。`[doc]`

```
$a [cde]
A C1 $a3        ; 「[cde] を 3 回」にはならない
```

この場合、`$a` は `cdecde`（回数省略時の 2 回）に展開され、続く `3` は
**展開結果の末尾のトークンに連結されます**。つまり `cdecd` + `e3` となり、
最後の `e` だけが 3 分音符になります。`[obs]`

意図した書き方は次のどちらかです。`[doc]`

```
$a cde
A C1 [$a]3

$a [cde]3
A C1 $a
```

### その他

- 文字列（`"…"`）の中ではマクロ展開されません。`[doc]`
- マクロの本体を文字列にすることはできます。`[doc]`
  ```
  $a "violin"
  A  C1"1st."+$a
  ```

## 3.2 長い名前のマクロ `${名前}` `[fork]`

```
${GM_RESET}     EXx7e,x7f,x09,x01,xf7
${MAIN_THEME}   l4 cde g2

A ${GM_RESET} r%24
A ${MAIN_THEME} ${MAIN_THEME}
```

- 名前に使えるのは英数字と `_`。大文字小文字は区別されます。長さの制限はありません。
- **定義は使用より後ろに書いてもかまいません。マクロの中で別のマクロを使う場合も
  同じです。** 旧方式と違い、順序の制約がありません。`[obs]`
- 同じ名前を 2 度定義した場合、後の定義が有効になります。`[obs]`
- 文字列（`"…"`）の中では展開されません。
- 未定義の名前を呼ぶとエラー（`undefined macro '${…}'`）。`[obs]`
  ただし名前が旧方式の形（`[0-9]?[a-z]`）で引数も無い場合は、旧方式のマクロ
  として扱われます。
- 自己再帰・相互再帰は深さ 100 で打ち切ってエラーになります。

### ループの扱いが旧方式と違う

長い名前のマクロは**テキストとして展開される**ため、本体の `[ ]` ループが
自己完結していなくてもかまいません。`[obs]`

```
${LOOP} [cde]
A C1 ${LOOP}3      ; 「[cde]3」＝ cde を 3 回。旧方式とは結果が違う
```

**この 1 点だけが、外部プリプロセッサ mmlpp と本フォークの差です。** mmlpp は
すべてのマクロをテキスト展開するため、旧方式と同じ形の名前でもこの挙動でした。
本フォークでは長い名前のマクロだけがこの挙動になります。`[fork]`

### 行数を変えない

マクロ本体は必ず 1 行に収まるため、1 入力行が必ず 1 出力行になります。
このため展開してもエラー報告の行番号と `# 行番号 "ファイル名"` マーカがずれません。`[fork]`

## 3.3 引数つきマクロ `${名前:引数1,引数2,…}` `[fork]`

マクロ本体に `#1`, `#2`, … と書くと、呼び出し側の引数が埋め込まれます。

```
${MIXER}  v#1 p#2 y91,#3 y93,#4

B @37 ${MIXER:120, 64, 30, 20}
C @31 ${MIXER:115, 64, 55,  0}
```

規則:

| 項目 | 規則 |
| --- | --- |
| 10 個目以降 | `#{10}` のように番号を `{ }` で囲む。`#10` は「1 番目の引数に `0` を繋げたもの」 |
| 引数中の `,` | `\,` と書く |
| 引数中の `\` | `\\` と書く |
| `{ }` で囲んだ部分 | その中の `,` は区切りと見なされない。`${a:{x40,x01,x30,x00}}` のように書ける。波括弧ごと引数に含まれ、`\` は 1 段だけ剥がされる |
| 引数の個数 | **検査しない。** 足りない分は空文字列、余った分は捨てる |
| 呼び出しの記法 | 引数を渡すときは名前が短くても必ず `{ }` が必要（`$a:x,y` とは書けない）。定義行は `$a cde#1#2` でもよい |
| 文字列の中 | `#1` は置換されない |

## 3.4 展開の順序

長い名前のマクロの展開は、**行の前処理の最終段**で行われます
（[01-lexical.md](01-lexical.md) 1.2 参照）。したがって:

- `#include` はマクロ展開より前に済んでいます。インクルード先で定義したマクロを
  インクルード元で使えるのはこのためです。`[obs]`
- 旧方式の `$a` は、この段階では触られません。展開結果に `$a` が残っていれば、
  後のコマンド解釈時に旧方式として処理されます。`[fork]`
