# 12. 適合性の検証

## 12.1 判定基準

再実装がこの仕様に適合しているとは、次を満たすことを言います
（[README.md](README.md) の再掲）。

1. **バイト一致。** 同じ入力 MML・同じオプションに対し、生成される SMF が
   現行実装の出力とバイト単位で一致する。**これが最終的な判定基準です。**
2. **診断の一致。** エラーになる入力ではエラーになり、正常終了する入力では
   正常終了する（メッセージの文面までの一致は求めない）。
3. **進捗表示の一致は求めない。**

## 12.2 プローブの書き方

黒箱で 1 つの挙動を確かめる最小の手順です。仕様に `[obs]` を足すときは、
必ずこの形で裏を取ってください。

```sh
#!/bin/sh
# usage: probe <name> <mml-text> [opts...]
EXE=build/Release/mml2mid.exe
n="$1"; shift
printf '%b' "$1" > "$n.mml"; shift
echo "=== $n ==="
"$EXE" "$@" "$n.mml" "$n.mid" 2>&1 | grep -v '^MML->MID'
od -An -tx1 -v "$n.mid"
rm -f "$n.mid"
```

```
$ probe q3 'A C1 q3 c4\n'
=== q3 ===
   trk 0A:      48 steps ""
 4d 54 68 64 …  90 3c 64 2d 3c 00 03 ff 2f 00
                         ↑ ゲートタイム 45 = 48 − 3
```

### 注意

- **`%` はシェルの `printf` で書式指定として食われます。** `%%` と重ねてください。
- 差を見たい 1 点以外は固定してください。既定のトラック（`A C1`）、既定の
  timebase、既定の `l` / `q` / `k` から始めるのが安全です。
- 出力の先頭 14 バイトは常にヘッダです（`4D 54 68 64 00 00 00 06 …`）。
  第 1 トラックの `00 FF 03 00 00 FF 02 00 00 FF 2F 00` も定型なので、
  読むのは 2 本目の `MTrk` からで足ります。

## 12.3 検証コーパス

| 群 | 場所 | 常時実行 | 内容 |
| --- | --- | --- | --- |
| トラック名 | `test/trackname/` | ○ | 名前の文法・並列・ワイルドカード・2 文字名 |
| 不具合修正 | `test/regress/` | ○ | TODO 由来の修正と対照ケース |
| デバッグマップ | `test/dbgmap/` | ○ | `-g` 有無で SMF が一致すること、マップが期待値と一致すること |
| 診断 | `test/diag/` | ○ | `--diag=json` の JSON |
| サンプル曲 | `sample/` | × | オリジナル配布物の 32 曲。**非同梱** |

サンプル曲の回帰テストは、[オリジナル配布物](https://www.vector.co.jp/soft/dl/unix/art/se102432.html)の
`sample/` をツリー直下にコピーすると有効になります。`.mml` は **EUC-JP のまま
無改変で**置いてください（文字コードを変えると生成 MIDI が変わります）。

### コーパスから除外すべきもの

> **`kr`（ランダムベロシティ）を使う MML。** 出力が決定的でないため、
> バイト一致で検証できません（[11-quirks.md](11-quirks.md) 11.3）。

## 12.4 再実装のための検証の進め方

仕様書の `[?]` を潰しながら実装する場合の順序の目安です。

1. **字句とヘッダ。** 空の MML から始め、`MThd` と第 1 トラックの定型部分を
   一致させる。ここで `#timebase` と `#title` / `#copyright` が確定する。
2. **1 音。** `A C1 c` のバイト列を一致させる。ノートオン・ゲートタイム・
   ノートオフの表現・デルタタイムがここで確定する。
3. **音長式。** [05-time.md](05-time.md) の実測表をそのままテストにする。
4. **ゲートタイム。** `q` / `Q` / 音符の第 2 引数の組み合わせ。
5. **コントロールチェンジと重複除去。** [07-commands.md](07-commands.md) の
   出力バイト列の表をテストにする。`s` の解除も。
6. **ランニングステータス。** メタ・SysEx をまたぐ挙動（[09-output.md](09-output.md) 9.5）。
7. **複数トラックと出力順序。** [04-tracks.md](04-tracks.md) 4.6。
8. **エンベロープと LFO。** 補間と丸めが残った `[?]` の本丸。
9. **`=` の書き戻し。** 最も複雑。`test/regress/psw-*.mml` が既にある。
10. **サンプル曲 32 件。** `kr` を使う 1 曲を除いた 31 件でバイト一致を目指す。

## 12.5 差分の調べ方

```sh
# 現行実装と再実装の出力を比較
cmp -l a.mid b.mid | head

# 人間が読める形に落として diff
od -An -tx1 -v a.mid | tr -s ' ' '\n' > a.hex
od -An -tx1 -v b.mid | tr -s ' ' '\n' > b.hex
diff a.hex b.hex | head -40
```

デルタタイムがずれると以降が全部ずれるため、**最初の差分の位置だけを見て、
そこまでのイベントを数え直す**のが早道です。
