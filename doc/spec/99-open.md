## 初版から確定させた項目（16 件）

参考として、実測で潰した項目を記録します。反映先は各文書。

| 項目 | 結論 | 反映先 |
| --- | --- | --- |
| エンベロープの補間の端数処理 | **floor(基準値 + 変位 × t / 区間長)** | [08](08-envelope.md) 8.1 |
| 変位区間の最後の点を書くか | **ゲートタイムの範囲内なら書く** | [08](08-envelope.md) 8.1 |
| LFO の位相の起点 | **ディレイ終了時。書き込みは `n3 + k×n2`** | [08](08-envelope.md) 8.2 |
| `FW` / `IW` の出力形式 | **14 ビットのピッチベンド** | [08](08-envelope.md) 8.2.1 |
| `FA` / `IA` の出力形式 | **チャンネルプレッシャー、基準値 0** | [08](08-envelope.md) 8.2.1 |
| エンベロープが音符をまたぐ場合 | **各ノートオンの直前に基準値へ書き戻して再スタート** | [08](08-envelope.md) 8.1 |
| `y` が重複除去の対象か | **追跡対象の CC 番号のときだけ。状態を共有する** | [07](07-commands.md) 7.2 |
| 重複除去の対象の完全な一覧 | **追跡している 5 状態のみ** | [07](07-commands.md) 7.2 |
| 同一 tick のエンベロープと音符の順序 | **エンベロープが先** | [09](09-output.md) 9.8 |
| `M` のディレイの条件 | **`n1 < ゲートタイム`（厳密）** | [07](07-commands.md) 7.7 |
| `#xtempo` の丸め | **`round(60000000×100/(テンポ×xtempo))` を 1 回で計算** | [02](02-directives.md) 2.9 |
| `Q` の除算の端数処理 | **四捨五入。ただし `Q≠0` なら下限 1** | [05](05-time.md) 5.4 |
| ゲートタイムの下限 | **0** | [05](05-time.md) 5.4 |
| ノートナンバーのクランプ | **0〜127。エラーにならない** | [06](06-notes.md) 6.6.1 |
| `FF 58` の第 3・第 4 バイト | **`18` / `08` の固定値**（timebase に依存しない） | [07](07-commands.md) 7.8 |
| `BS` と `BW` の対応 | **`BS64` ≡ `BW8192`。状態を共有し重複除去される** | [07](07-commands.md) 7.5 |
