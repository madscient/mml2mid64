# 02. 定義行（ディレクティブ）

> 完成度: 全ディレクティブを網羅。テンポ値の算出式を実測で確定。`[?]` が 6 件。

行頭が `#` の行です。`#` の直後にディレクティブ名を書きます。

## 2.1 全体に効くという性質

**ほぼすべてのディレクティブは、ファイル中のどこに書いてもファイル全体に効きます。**
「この行より後だけ」という局所的な指定はできません。`[doc]` `[obs]`

```
A C1 h        ; #german が後ろにあっても、この h は「シ」として解釈される
#german
```

同じディレクティブを複数回書いた場合の規則はディレクティブごとに異なります
（トグル型か、後勝ちか）。各項を参照してください。

例外は `#include` と `# 行番号 "ファイル名"` で、これらは書かれた位置で作用します。

| `#swap<>` | なし（トグル） | `[doc]` |

## 2.3 `#title "文字列"`

曲名。**SMF メタイベント `FF 03`（Sequence/Track Name）**として、
FORMAT 1 では第 1 トラック（テンポマップ）の先頭に、FORMAT 0 では出力の先頭に
書かれます。`[obs]`

- 最大 255 バイト。`[fork]`（オリジナル版は 256 バイトを受け付けて長さ 0 として
  書き出す不具合があった。[11-quirks.md](11-quirks.md) 参照）
- **`#title` を書かなかった場合も `FF 03` は長さ 0 で必ず出力されます。** `[obs]`
  ```
  00 ff 03 00        ; #title 無しのときの第1トラック先頭
  00 ff 03 02 48 69  ; #title "Hi" のとき
  ```
- `#` で始まる行の文字列なので、`+` による連結は使えません。`[doc]`

## 2.4 `#copyright "文字列"`

著作権表示。**SMF メタイベント `FF 02`（Copyright Notice）**として、`FF 03` の
直後に書かれます。`[doc]` `[obs]`

- 最大 255 バイト。`[fork]`
- **書かなかった場合も長さ 0 で必ず出力されます。** `[obs]`

## 2.5 `#timebase n`

4 分音符あたりのステップ数。**SMF ヘッダの division にそのまま書かれます。** `[obs]`

- 既定値は 48。`[doc]`
- 説明書は 48, 60, 80, 96, 120, 160, 240, 480 が指定可能としていますが、
  **実装は値を検査しません。** `#timebase 50` は受理され、division に 50 が
  書かれます。`[obs]`（[11-quirks.md](11-quirks.md)）
- 複数回書いた場合は**最後のものが有効**です。`[obs]`
- 上限・下限、0 や負値の扱いは未確認。`[?]`

## 2.6 `#include "ファイル名"`

指定したファイルをその位置に読み込みます。再帰的に展開されます。`[doc]`

- **文字列中の `\` はエスケープとして解釈されます。** Windows のパスを書く場合は
  `/` を使うか `\\` と重ねてください。`[doc]`
- インクルード先で定義したマクロは、インクルード元でも使えます。`[fork]` `[obs]`
- エラーは、インクルード先のファイル名と行番号で報告されます。`[fork]`
- 再帰の深さの上限、ファイルが見つからない場合の検索パスは未確認。`[?]`

## 2.7 `#swap<>` / `#swap()`

`#swap<>` は `>` と `<`（オクターブの上下）の効果を入れ替えます。
`#swap()` は `)` と `(`（ベロシティの上下）の効果を入れ替えます。`[doc]`

- **トグルです。** 偶数回書くと元に戻ります。`[doc]`
- ファイル全体に効きます。局所的な入れ替えはできません。`[doc]` `[obs]`
- コマンドラインの `-x` / `-v` と同じ効果で、こちらもトグルです。`[doc]`

## 2.8 `#german`

ドイツ式の音名を使います。`[doc]`

| 指定 | `h` | `b` |
| --- | --- | --- |
| `#german` なし | エラー | シ |
| `#german` あり | シ | シのフラット（`h-` と同じ） |

- ファイル全体に効きます。書いた位置より前の `h` も「シ」になります。`[obs]`
- `#german` 指定時、調号（`KJ` / `KI`）は `h` には効きますが `b` には効きません。
  `b` は常に `h-` と同じ音です。`[doc]`
- `#german` 指定時、`KJb` / `KIb` の後ろには `+` も `-` も付けられません。`[doc]`

## 2.9 `#xtempo n`

曲全体のテンポを **n/100 倍**します。`[doc]`

```
#xtempo 50
A C1 t120 c      ; FF 51 03 0F 42 40（1000000µs = 60 BPM）
```

`t120` は本来 `FF 51 03 07 A1 20`（500000µs）ですが、`#xtempo 50` により
実演奏が半分の速さになるよう µs/4分音符が倍になります。`[obs]`

- 複数回書いた場合は最後のものだけがファイル全体に効きます。部分的な倍率変更は
  できません。`[doc]`

### テンポ値の算出

> **µs/4分音符 = round(60000000 × 100 / (テンポ値 × xtempo))**
>
> **1 回の計算で四捨五入します。** テンポを先に丸めてから倍率を掛けるのでは
> ありません。`[obs]`

実測:

| 記述 | 出力 | 検算 |
| --- | --- | --- |
| `t7` | `82 CA 25` = 8571429 | 60000000/7 = 8571428.57 → 8571429 |
| `t13` | `46 6C D9` = 4615385 | 60000000/13 = 4615384.62 → 4615385 |
| `t65535` | `00 03 94` = 916 | 60000000/65535 = 915.54 → 916 |
| `#xtempo 33` + `t120` | `17 1E 90` = 1515152 | 6000000000/3960 = 1515151.52 → 1515152 |
| `#xtempo 101` + `t120` | `07 8D CA` = 495050 | 6000000000/12120 = 495049.50 → 495050 |
| `#xtempo 200` + `t7` | `41 65 12` = 4285714 | 6000000000/1400 = 4285714.29 → 4285714 |

最後の 1 件が 2 段階計算を否定します。先に `t7` を 8571429 へ丸めてから 2 で
割ると 4285714.5 → 4285715 になり、実測と合いません。`[obs]`

## 2.10 `#bc525`

Ver 5.25 以前との互換動作に戻します。`[doc]`

| 記法 | `#bc525` なし | `#bc525` あり |
| --- | --- | --- |
| `*` | 音符の後ろに付けるナチュラル | `__`（相対移調）と同じ |
| 音符の後の `--` | ダブルフラット | 1 つ目がフラット、2 つ目が音長の減算 |
| `*n` | 使えない | `__n`（相対移調） |

## 2.11 `# 行番号 "ファイル名"`

外部プリプロセッサとの連携用のマーカです。`#` は行頭になければなりません。`[doc]`

この行以降でエラーが起きた場合、指定した「ファイル名」の、指定した「行番号」から
数えた位置でエラーが起きたものとして報告されます。

```
# 19 "foo.mml"
```

この行の 4 行先でエラーが起きた場合、`foo.mml` の 22 行目（= 19 + 4 - 1）として
報告されます。`[doc]`

本フォークではこのマーカを自前で生成するため（[03-macros.md](03-macros.md)、
`#include` 展開）、外部プリプロセッサを使う必要は通常ありません。`[fork]`

## 2.12 `#ampasandtie <on|off>` `[fork]`

`&` の意味を切り替えます。既定値は `off`。詳細は [06-notes.md](06-notes.md)。

| 値 | `&` の意味 |
| --- | --- |
| `off`（既定） | ノートオフを抑制して次の音を重ねる（和音を作る） |
| `on` | タイ／スラー。同音は音長を合算、異音はレガート（CC#68）で繋ぐ |

- ファイル全体に効きます。`[fork]`
- `off` のままなら生成される SMF は一切変わりません。`[fork]`

## 2.13 `#sysexsinglequote <on|off>` `[fork]`

`EX` / `EE` コマンド中の文字列埋め込みの区切り文字を `"` から `'` に変えます。
既定値は `off`。詳細は [07-commands.md](07-commands.md)。

- **`'…'` を使う行より前に書く必要があります。** 注釈の除去が行を読んだその場で
  行われるためで、他のディレクティブと違ってこれだけ位置に依存します。`[fork]`
- `on` のとき `"…"` は使えません。混在不可。`[fork]`

## 2.14 `#bendrange <1〜24>` `[fork]`

数値表記 `i` / `j`（半音数からピッチベンド値を算出）の基準ベンドレンジ。
既定値は 2。範囲外はエラー。`[fork]`

- マクロ `${_bend_range_}` に数値を定義しても同じ意味になります（外部プリプロセッサ
  mmlpp との互換）。両方書いた場合は `#bendrange` が優先されます。`[fork]`
- この機能を使うトラックでは、`BR` コマンドで音源側にも同じ値を設定する必要が
  あります（処理系は検査しません）。`[fork]`

## 2.15 `#pswflush <バイト数>` `[fork]`

演奏スイッチ `=0` での状態書き戻しにおける、1 tick あたりの最大バイト数。
詳細は [04-tracks.md](04-tracks.md)。

- 省略時は `1562 / timebase`（1 未満なら 1）。`[fork]`
  MIDI は 31250 bps・1 バイト 10 ビットで毎秒 3125 バイト、テンポ 120 では
  1 tick が `500 / timebase` ミリ秒なので、その間に送れるバイト数です。
