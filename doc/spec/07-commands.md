# 07. コマンド一覧（音符以外）

> 完成度: 主要コマンドの出力バイト列と重複除去の一覧を実測で確定。`[?]` が 5 件。
> 音符・休符・連結は [06-notes.md](06-notes.md)、エンベロープは [08-envelope.md](08-envelope.md)。

**コマンド文字は大文字・小文字を区別します。**

## 7.1 チャンネルとトラック名

### `Cn`

そのトラックの出力する MIDI チャンネル（1〜16）。`[doc]`

- **各トラックの一番最初に必ず指定してください。** `[doc]`
- トラックの途中でも変更できます。
- **このコマンドが指定されると `s` コマンドの効果が自動的に発効します**
  （重複除去が次の 1 回だけ解除される）。`[doc]`

### `Cn"文字列"`

チャンネル指定の直後に文字列を書くとトラック名になります。
**SMF メタイベント `FF 03`** として、そのトラックの先頭に出力されます。`[doc]` `[obs]`

`+` による文字列の連結が使えます。`[doc]`

## 7.2 重複除去と `s`

> **mml2mid は無駄なコントロールチェンジとピッチベンドを出力しません。**
> 既に現在値が目的の値と同じなら、そのイベントは出力されません。`[doc]` `[obs]`

```
A C1 v100 c v100 c        ; CC7=100 は 1 回しか出力されない
A C1 v100 c s v100 c      ; s を挟むと 2 回出力される
```

`s` コマンドは、**Volume / Expression / Panpot / Modulation / Pitch Bend の
それぞれに対して、次の 1 回だけ**重複除去を解除します。`[doc]`

- 各対象に個別に書く必要はありません。`s v120 E100 p64` で 3 つとも効きます。`[doc]`
- `Cn` によるチャンネル変更時は自動的に発効します。`[doc]`

### 対象の完全な一覧

> **重複除去されるのは「処理系が現在値を追跡している 5 つの状態」だけです。**
> それ以外のコントロールチェンジは、同じ値でも書いた回数だけ出力されます。`[obs]`

| 状態 | 対応する MIDI | 重複除去 |
| --- | --- | --- |
| ボリューム | CC#7 | **する** |
| エクスプレッション | CC#11 | **する** |
| パンポット | CC#10 | **する** |
| モジュレーション | CC#1 | **する** |
| ピッチベンド | `En` | **する** |
| チャンネルプレッシャー（`G`） | `Dn` | しない |
| バンクセレクト（`H`） | CC#0 / CC#32 | しない |
| プログラムチェンジ（`@`） | `Cn` | しない |
| RPN / NRPN のデータ（CC#6） | CC#6 | しない |
| ペダル類（`P` / `X`） | CC#64〜68 | しない `[fork]` |
| その他の CC（`y91` など） | | しない |
| テンポ（`FF 51`） | | しない |

**`y` で追跡対象の CC 番号に書いた場合は、対応するコマンドと完全に同じ扱いに
なります。** 状態の読み書きを共有します。`[obs]`

```
A C1 y10,20 y10,20        ; 2 つ目は消える（CC#10 = パンポット）
A C1 p64    y10,64        ; 2 つ目は消える
A C1 y7,20  v20           ; v20 が消える（y7 がボリューム状態を更新している）
A C1 y91,10 y91,10        ; どちらも出る（CC#91 は追跡対象外）
```

**RPN / NRPN はアドレス指定（CC#101/100/99/98）だけが重複除去されます。**
データ（CC#6）は毎回出るため、`TC10 TC10` は 2 つ目が `B0 06 0A` の 1 イベントに
なります。`[obs]`

エンベロープと LFO の書き込みも、追跡対象への書き込みなので重複除去されます
（[08-envelope.md](08-envelope.md)）。`[obs]`

## 7.3 コントロールチェンジ系

実測した出力バイト列（チャンネル 1、`b0` は CC のステータス）:

| コマンド | 意味 | 出力 | 初期値 | 出典 |
| --- | --- | --- | --- | --- |
| `vn` | ボリューム（0〜127） | `B0 07 nn` | 不定 | `[doc]` `[obs]` |
| `En` | エクスプレッション | `B0 0B nn` | 不定 | `[doc]` `[obs]` |
| `pn` | パンポット（0〜127、中央 64） | `B0 0A nn` | 不定 | `[doc]` `[obs]` |
| `yn1,n2` | 任意のコントロールチェンジ | `B0 n1 n2` | | `[doc]` `[obs]` |
| `Hn1,n2` | バンクチェンジ | `B0 00 n1` + `B0 20 n2` | | `[doc]` `[obs]` |
| `MONn` | 無条件モジュレーション（0〜127） | `B0 01 nn` | | `[doc]` `[obs]` |
| `MOF` | `MON` / `M` の解除（`MON0` と同じ） | `B0 01 00` | | `[doc]` `[obs]` |
| `Gn` | チャンネルプレッシャー（0〜127） | `D0 nn` | | `[doc]` `[obs]` |
| `Yn` | モノ／ポリモード切替 | `B0 7E nn`（`n`=1〜127）/ `B0 7F 00`（`n`=0） | 省略時 1 | `[fork]` |

`v` `E` `p` `BS` `BW` は `+n` / `-n` による相対指定ができます。`[doc]`

`pn` は `n` を省略すると `n=2` と同じ扱いになります。`[doc]` `[?]`

`pn1,n2,n3` は `k` と同じ第 2・第 3 引数（キーオンごとの変化量、反射スイッチ）を
取ります。`[doc]`

### `P` / `X` — ペダル類

`P` がオン（値 127）、`X` がオフ（値 0）。引数 0〜4 で対象を選びます。`[fork]`

| 引数 | 対象 | CC |
| --- | --- | --- |
| `0`（省略時） | ダンパー・ペダル | 64 |
| `1` | ポルタメント | 65 |
| `2` | ソステヌート | 66 |
| `3` | ソフト・ペダル | 67 |
| `4` | レガート | 68 |

引数を省略した `P` / `X` はオリジナル版と同じ CC#64 です。0〜4 以外はエラー。`[fork]`

実測: `P` → `B0 40 7F`、`X` → `B0 40 00` `[obs]`

## 7.4 プログラムチェンジ

| コマンド | 意味 | 出力 | 出典 |
| --- | --- | --- | --- |
| `@n` | プログラムチェンジ（0〜127） | `C0 nn` | `[doc]` `[obs]` |
| `@+n` / `@-n` | 以降のプログラム番号すべてに加えるオフセット | | `[doc]` |
| `@(msb,lsb,prog)` | バンクセレクト付き | `B0 00 msb` + `B0 20 lsb` + `C0 prog` | `[fork]` |

- `@(…)` は `Hmsb,lsb @prog` と完全に同じバイト列を出力します。`[fork]`
- `@+n` のオフセットは `@(…)` の `prog` にも適用されます。`[fork]`
- 3 つの引数はすべて必須。個数が合わないとエラー。`[fork]`

## 7.5 ベンドとチューニング

| コマンド | 意味 | 出力 | 出典 |
| --- | --- | --- | --- |
| `BSn` / `~n` | ベンド（0〜127） | `E0 00 nn`（LSB は常に 0） | `[doc]` `[obs]` |
| `BWn` | 2 バイトベンド（0〜16383） | `E0 lsb msb`（14 ビット） | `[doc]` `[obs]` |
| `BBn` | 相対ベンド（`BS+n` / `BS-n` と同じ。旧互換） | | `[doc]` |
| `BRn` | ベンドレンジ | RPN 0,0: `B0 65 00` `B0 64 00` `B0 06 nn` | `[doc]` `[obs]` |
| `Dn` | ディチューン（−64〜63） | RPN 0,1: `B0 65 00` `B0 64 01` `B0 06 (n+64)` | `[doc]` `[obs]` |

`BS127` は `BW16256` に、`BS64` は `BW8192` に対応します。`[doc]` `[obs]`

`~` の直後が音名として解釈できる場合はノート連結になります（[06-notes.md](06-notes.md)）。`[fork]`

### `i` / `j` — 半音数からベンド値を算出 `[fork]`

数値を取る位置で使える表記です。`i` は `~` / `BS` 用の 0〜127 を、`j` は
`FB` / `UB` 用の −64〜63 を返します。

```
#bendrange 8
A BR8
A l4 c&~i2r ~i0          ; c から 2 半音上へスラー、そして戻す
A FB1, 0, 4,j-2 a4 FB0   ; a から 2 半音下へ 4 分音符かけて下げる
```

算出:

> `clamp(64.0 × 半音数 / ベンドレンジ + 64.0, 0, 127)` を求め、
> **クランプしてから** `+0.5` して切り捨てる。`j` はさらに `−64`。

- 符号は `i-2` のように**文字の後ろ**に書きます。
- 基準レンジは `#bendrange`（既定 2）。トラック側で `BR` に同じ値を設定する必要が
  あります（処理系は検査しません）。
- レンジを超える半音数はエラーにせず 0〜127 に収めます。
- `i2+3` のような加減算の連結が使えます。
- `BW` 用（0〜16383）を算出する機能はありません。

## 7.7 モジュレーション

### `Mn1,n2` — ディレイ付きモジュレーション

ノートオン後 `n1` クロック後に、モジュレーション（CC#1）を `n2` にします。
初期値は `M0,0`。`[doc]`

- **`M0,0` または `MOF` が来るまで、ノートオンするごとに毎回働きます。** `[doc]`
- ノートオン時にモジュレーションを 0 に設定 → `n1` クロック後に `n2` に設定 →
  **次のキーオンの直前**に 0 に戻します。`[doc]`
  （Ver 5.0 以前はキーオフ直後に戻していました）
- `MONn` を書くと `M` の効果は解除されます。`[doc]`

> **発行の条件は `n1 < ゲートタイム`（厳密な不等号）です。** `[obs]`
> 満たさない場合、ノートオン時の「0 に設定」だけが行われ、`n2` への設定は
> 出力されません。

実測（`c4`、`q` 既定＝ゲートタイム 47）:

| 記述 | 結果 |
| --- | --- |
| `M46,50 c4` | tick 46 で `B0 01 32` を出力 |
| `M47,50 c4` | 出力しない |
| `M48,50 c4` | 出力しない |
| `M100,50 c4` | 出力しない |

実測（`M20,50 c4 c4`）:

```
tick  0 : B0 01 00   （0 に設定）
tick  0 : 90 3C 64   （ノートオン）
tick 20 : B0 01 32   （n2 に設定）
tick 47 : 3C 00      （ノートオフ）
tick 48 : B0 01 00   （次のキーオンの直前に 0 へ戻す）
tick 48 : 90 3C 64   （次のノートオン）
```

`n1` は `&n`（n 分音符指定）で書けます（`M&4.,120`）。`[doc]`

## 7.8 テンポと拍子

| コマンド | 意味 | 出力先 | 出典 |
| --- | --- | --- | --- |
| `tn` | テンポ（1〜65535） | FORMAT 1 では第 1 トラック | `[doc]` `[obs]` |
| `t+n` / `t-n` | 相対指定 | | `[doc]` |
| `t(n` | 現在のテンポをスタックに退避して新しい値を設定（`n` 省略可） | | `[doc]` |
| `t)` | 退避したテンポを復帰 | | `[doc]` |
| `BTn1,n2` | 拍子（分子 n1、分母 n2） | FORMAT 1 では第 1 トラック | `[doc]` `[obs]` |

- テンポは複数のトラックに散らばっていてもかまいません。`[doc]`
- 初期値は不定です。`[doc]`

出力形式 `[obs]`:

```
t120     →  FF 51 03 07 A1 20        （500000 µs/4分音符）
BT6,8    →  FF 58 04 06 03 18 08     （6/8拍子, clocks/click=24, 32nds/quarter=8）
```

`FF 58` の第 2 バイトは分母の 2 を底とする対数です（`4`→`2`, `8`→`3`, `16`→`4`,
`2`→`1`）。`[obs]`

**第 3・第 4 バイトは `18`（24）と `08`（8）の固定値です。** `#timebase` を
48 / 96 / 240 に変えても変わりません。`[obs]`

`#xtempo n` が指定されている場合、µs/4分音符は n/100 で割った値になります
（[02-directives.md](02-directives.md)）。`[obs]`

実測:

```
A C1 t120 c t(-30 c t) c
→ FF 51 03 07 A1 20  (tick 0)
→ FF 51 03 0A 2C 2B  (tick 48, テンポ 90)
→ FF 51 03 07 A1 20  (tick 96, 復帰)
```

## 7.10 エクスクルーシブ

### `EXn1,n2,…`

エクスクルーシブを送信します。`F0` と長さが自動的に付き、末尾に終端コード
`F7` を自分で書きます。`[doc]` `[obs]`

```
A EXx41,x10,{x40,x00,x7f},xf7
→ F0 07 41 10 40 00 7F 41 F7
```

長さバイトは **`F0` の後ろのバイト数**（この例では 7）です。`[obs]`

主なメーカー ID `[doc]`: `x40` KAWAI / `x41` ROLAND / `x42` KORG /
`x43` YAMAHA / `x44` CASIO / `x47` AKAI

### チェックサム `{ … }`

`{ }` で囲んだ範囲のチェックサムが、**閉じ括弧の直後**に挿入されます。`[doc]` `[obs]`

上の例では `40 00 7F` の総和 0xBF に対し `0x41` が挿入されています
（128 の補数）。`[obs]`

### 文字列の埋め込み

`EX` / `EE` の引数に `"文字列"` を書くと、その中身がバイト列として埋め込まれます。`[doc]`

`#sysexsinglequote on` を指定すると区切りが `'…'` に変わり、`"` を無変換で
埋め込めるようになります。`[fork]`

- `on` のとき `"…"` は使えません（混在不可）。
- 文字列の中の `{` `}` `,` は区切りとして解釈されませんが、チェックサムの
  計算対象にはなります。
- 埋め込む文字列は 7 bit ASCII を想定しています。マルチバイト文字をそのまま
  埋め込むと `0xF7` などと衝突して MIDI メッセージ列が壊れます。

### バルクダンプ整形

| 記法 | 方式 |
| --- | --- |
| `{N…}` | Niblize（GS 音源など）。上位 4 ビットと下位 4 ビットを分けて送る |
| `{T…}` | KORG TR-Rack 方式。8 ビット 7 個を 7 ビット 8 個に整形する |

`[doc]`

```
{Nx80,xff,xc7}                     → x08,x00,x0f,x0f,x0c,x07
{Tx80,xff,xc7,x40,x55,x67,xd9}     → x47,x00,x7f,x47,x40,x55,x67,x39
```

T 方式の整形:
```
整形前: n0[b7-b0], n1[b7-b0], …, n6[b7-b0]
整形後: [n6b7…n0b7], n0[b6-b0], n1[b6-b0], …, n6[b6-b0]
```

- 括弧の中では 8 ビット長（x00〜xff）と負の値（−128 まで）が使えます。`[doc]`
- **チェックサムの括弧はバルク整形の括弧より外側でのみ使えます。** `[doc]`

### ビット幅指定 `Bn_`

バルク整形の括弧の中では、数値の前に `Bn_`（n は 1〜8）を付けて中途半端な
ビット幅の数値を指定できます。`[doc]`

```
{NB4_x0f,B4_x08}              ≡ {Nxf8}
{NB3_x07,B6_x08,B7_x7f}       ≡ {Nxe4,x7f}
{NB3_-1,B6_8,B7_127}          ≡ 上と同じ（10 進・負数も可）
```

次の数値は前の 1 バイトの残りビットから格納され、入りきらない場合はバイト境界を
またぎます。半端な状態で括弧を閉じた場合、未格納のビットは 0 で埋められます。`[doc]`

### `EEn1,n2,…`

データを SMF に**直接**出力します（`F0` や長さを付けません）。`[doc]`

### `mv` / `mt` `[fork]`

GM2 のユニバーサル・リアルタイム SysEx を送出します。device ID は全デバイス宛の
`0x7F` です。

| コマンド | 範囲 | 出力 |
| --- | --- | --- |
| `mvn` | 0〜127 | `F0 7F 7F 04 01 00 nn F7` |
| `mtn` | −8192〜8191 | `F0 7F 7F 04 03 ll mm F7`（14 ビット値 = n + 0x2000） |

引数の省略・範囲外はエラー。`mv` / `mt` 以外の `m?` もエラー。`[fork]`

## 7.13 リズムパート `RT`

そのトラックをリズムパートに指定します。`[doc]`

- コマンドラインの `-tn`（移調）が効かなくなります。`[doc]`
- **ノートオンと同じステップでノートオフします**（`q` コマンドを使う必要が
  ありません）。`[obs]`

実測: `RT c4` → `90 3C 64` `00` `3C 00` `30`（ゲートタイム 0）`[obs]`

`org-doc/mml2mid.txt` は「1 クロック後にノートオフ」と書いていますが、
実測値は 0 です。[11-quirks.md](11-quirks.md) 参照。

## 7.14 進捗表示 `S`

コンパイル時に、その時点のステップ数などをコンパイラの出力へ表示します。`[doc]`

表示される項目: ステップ数、バンク番号、プログラム番号、オクターブ、ボリューム、
ベロシティ、エクスプレッション、パンポット、ベンド、ゲートタイム、第 2 ゲートタイム、
基本音長。`[doc]`

**SMF には何も出力しません。表示形式は仕様外とします**（[README.md](README.md) の
適合性の定義）。

## 7.15 旧互換コマンド

なるべく使わないこととされているものです。`[doc]`

| 記法 | 同等の記法 |
| --- | --- |
| `\n` | `rn&`（休符に `&` を付けたもの）と全く同等 |
| `/` | `:`（ループアウト） |
| `BBn` | `BS+n` / `BS-n` |
| `*n` | `__n`（`#bc525` 指定時のみ） |
