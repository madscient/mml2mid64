# 11. 説明書との食い違い・非直感的な挙動・既知の限界

再実装で踏み抜きやすい箇所を集めています。**`org-doc/` の説明書を読んだだけでは
分からない、あるいは説明書が間違っている項目です。**

## 11.1 説明書と実装が食い違う

| # | 説明書の記述 | 実際の挙動 | 影響 |
| --- | --- | --- | --- |
| 1 | `#timebase` は 48, 60, 80, 96, 120, 160, 240, 480 が指定可能 | **値を検査しない。** `#timebase 50` は受理され division に 50 が書かれる | 出力 |
| 2 | 音符の第 2 引数は「ゲートタイム」 | **`q` の第 1 引数と同じ「短縮量」。** `c4,100,10` のゲートタイムは 10 ではなく 38 | 出力 |
| 3 | `kn1,n2` は「n1 からベロシティが n2 ずつ増加」 | **最初の音符から既に n2 が加算されている。** `k64,10 cccc` → 74, 84, 94, 104 | 出力 |
| 4 | `RT` のトラックは「ノートオン後 1 クロックでノートオフ」 | **ゲートタイムは 0。** ノートオンと同じ tick でノートオフ | 出力 |
| 5 | `c&r2` は `c^2` と「ほぼ同じ意味」 | **ゲートタイムが違う。** `c&r2` は 144、`c^2` は 143 | 出力 |
| 6 | `I*`（LFO）の図は正弦波に見える | **三角波** | 出力 |
| 7 | `=1` の区間で変えた「全ての値」が `=0` の直後に反映される | オリジナル版では一部（`y`・`BS`・`BR`/`D`・`N`/`TC`/`TR`）が捨てられていた。本フォークで全種類を書き戻すよう修正済み `[fork]` | 出力 |
| 8 | `/*` は行頭に置く（`org-doc/command.txt`） | **行の途中でも受け付ける** | 文法 |

## 11.2 非直感的だが仕様どおり

| # | 項目 | 内容 |
| --- | --- | --- |
| 1 | **16 進数は 2 桁固定** | 桁が足りないと空白を読み飛ばして次の文字を食う。`vx4 c` は `v0x4c` と解釈され、`c` は音符として残らない。**エラーにならない** |
| 2 | **`^` / `-` は後ろから累算** | `c8-32-48` は「24 − (6 − 4) = 22」。「24 − 6 − 4」ではない |
| 3 | **`-` の曖昧性** | 音符の直後の `-` はフラット。音長の減算には `%` を挟む（`c%-8`） |
| 4 | **`&` は音長を合算しない**（既定） | `c&e&g4` は 144 ステップ。各音符が自分の音長分進む |
| 5 | **旧方式マクロのループは定義時に展開される** | `$a [cde]` に対し `$a3` は「[cde] を 3 回」にならない。展開結果の末尾トークンに `3` が連結され `cdecd` + `e3` になる |
| 6 | **トラックの出力順はソース順ではない** | 主トラック名の順 × 従属番号の順。`B`→`A`→`1A` と書いても `A`→`1A`→`B` の順に出る |
| 7 | **メタイベント・SysEx はランニングステータスを打ち切らない** | 一般的な SMF の慣行と異なる。バイト一致に直結する |
| 8 | **LFO の書き込みも重複除去される** | サンプル点がすべて中心値になるパラメータでは、イベントが 1 つも出ない |
| 9 | **テンポは重複除去されない** | 同じ値の `FF 51` が連続して出る |
| 10 | **`-c` は行頭空白の意味を反転する** | 指定なしでは行頭空白は無視、指定ありでは注釈行 |
| 11 | **`#title` / `#copyright` は無指定でも出力される** | 長さ 0 の `FF 03` / `FF 02` が第 1 トラックの先頭に必ず入る |
| 12 | **重複除去されるのは 5 つの状態だけ** | ボリューム・エクスプレッション・パンポット・モジュレーション・ベンドのみ。`G`・`H`・`@`・ペダル・`y91` などは同じ値でも書いた回数だけ出る |
| 13 | **`y` は CC 番号によって挙動が変わる** | 追跡対象の CC 番号（7, 11, 10, 1）に書くと、対応するコマンドと状態を共有して重複除去される。`y7,20 v20` は `v20` が消える |
| 14 | **`Q` の除算は四捨五入。ただし 0 にはならない** | `Q1 c%1`（0.125）でもゲートは 1。`Q0` のときだけ 0 になる |
| 15 | **エンベロープの補間は切り捨て** | 最終的な値に floor を適用する。四捨五入ではない |
| 16 | **`F*` は音符ごとに基準値へ書き戻す** | ノートオフの直後・次のノートオンの直前に、エンベロープ開始前の値が再送される |

## 11.3 決定的でないもの

> **`kr`（ランダムベロシティ）を使った MML は、コンパイルするたびに異なる SMF を
> 生成します。** `[obs]`
>
> バイト一致による適合性の検証ができません。検証コーパスからは除外してください。

## 11.4 既知の限界（未修正）

`org-doc/todo.txt` に挙げられ、構造的な理由で修正されていないものです。

| # | 項目 | 内容 |
| --- | --- | --- |
| 1 | **従属トラックと複数行にまたがる繰り返し** | 繰り返しの内側の行に付けた従属トラックは、常に 1 周目の位置にだけ整列する。作者自身が承知のうえで入れた意図的な近似 |
| 2 | **`=0` をはさむと `^n` が休符になる** | `^` による音長の加算は先読みで判定され、その先読みが `=` の行に当たると打ち切られる。「行頭に置く `=`」と「行をまたぐ音長継続」の構造的な衝突。警告は出る |
| 3 | **トラック終端の未クローズなノート** | 発音中のまま残った音は、何もノートオフされない `[fork]` |
| 4 | **デバッグマップとマクロ** | マクロ本体の中身は呼び出し行に潰れて記録される `[fork]` |

## 11.5 オリジナル版に存在した不具合（本フォークで修正済み）

再実装では**再現しないでください**。ただし、オリジナル版が生成した `.mid` と
照合する場合はこれらの差が出ます。

| # | 不具合 | 出典 |
| --- | --- | --- |
| 1 | `EX` / `EE` でのスタックバッファオーバーフロー（境界検査なし） | `[fork]` |
| 2 | `kr1`（または `kr n,0`）でゼロ除算 | `[fork]` |
| 3 | `S` コマンドが多いトラックで表示用バッファがオーバーフロー | `[fork]` |
| 4 | `#title` / `#copyright` が 256 バイトを受け付け、長さ 0 として書き出す | `[fork]` |
| 5 | SMF ヘッダのトラック数を 1 バイトでしか書いていない | `[fork]` |
| 6 | 主トラックより後ろに書いた従属トラック（`A1A`）が黙って捨てられる | `[fork]` |
| 7 | `M` コマンド × 音長 0 の和音で遅延モジュレーションが発行されない | `[fork]` |
| 8 | `=1`〜`=0` をまたぐとテンポ設定が無効になる | `[fork]` |
| 9 | `=1` があったかどうかのフラグが次のトラックへ漏れる | `[fork]` |

**6・7 は生成 MIDI が変わります。** オリジナル配布物の 32 サンプル曲のうち
4 曲がこの理由で変化しています（`test/README.md` の
"Samples this fork changed on purpose"）。

## 11.6 オリジナル版の `.mid` と一致しないサンプル

モダナイズ時点の記録では、同梱 `.mid` と**32 件中 28 件がバイト単位で完全一致**
しました。一致しない 4 件の理由:

| 原因 | 件数 |
| --- | --- |
| `kr` による乱数 | 1（`00master`） |
| テンポ値の丸め（各 1 バイト） | 2（`01hop2gs`, `10kazeir`） |
| 従属トラック取りこぼしの修正 | 1（`02nm63`） |

テンポ値の丸めの差は、**`#xtempo` の端数処理が確定していない**ことを示しています。
[02-directives.md](02-directives.md) の `[?]` 項目。
