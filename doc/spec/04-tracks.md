# 04. トラック

> 完成度: 名前の文法と出力順は実測済み。`=` の書き戻しは記述済み・未実測。`[?]` が 5 件。

## 4.1 トラック名の文法

```
トラック名 ::= [1-9]? [A-Z] [0-9]?
```

| 部分 | 意味 | 出典 |
| --- | --- | --- |
| 先頭の数字 `1`〜`9` | 従属トラック番号。省略時は主トラック | `[doc]` |
| 英大文字 `A`〜`Z` | 主トラック名の 1 文字目（必須） | `[doc]` |
| 末尾の数字 `0`〜`9` | 主トラック名の 2 文字目 | `[fork]` |

- 主トラックは 26 + 26×10 = **286 本**。従属トラックを含めて最大 **2860 本**。`[fork]`
  （オリジナル版は主トラック 26 本、出力できるトラック数の上限が 64 本 `[doc]`）
- `A0` は `A` とは**別のトラック**です。`[fork]`
- 進捗表示では従属番号を必ず 1 桁で表示します（主トラック `A` は `0A`、
  主トラック `A0` は `0A0`）。`[obs]`

## 4.2 並列表記

1 行の先頭に複数のトラック名を並べると、その行の内容がすべてのトラックに
書かれたのと同じになります。`[doc]`

```
AE f2^8fga
FG f8.fr8a-4
```

## 4.3 ワイルドカード `?`

`?` は**桁ごとに**展開されます。`[fork]`

| 書き方 | 意味 | 出典 |
| --- | --- | --- |
| `?` | `A`〜`Z`（1 文字のトラック名だけ） | `[doc]` `[obs]` |
| `1?` | `1A`〜`1Z` | `[doc]` |
| `?1?` | `A`〜`Z` と `1A`〜`1Z` | `[doc]` |
| `A?` | `A0`〜`A9` | `[fork]` `[obs]` |
| `?0` | `A0`〜`Z0` | `[fork]` |
| `??` | `A0`〜`Z9`（2 文字のトラック名すべて） | `[fork]` |
| `1??` | `1A0`〜`1Z9` | `[fork]` |

**2 文字目の `?` は `0`〜`9` を表すので、`A?` に 1 文字のトラック名 `A` は
含まれません。** `[fork]`

`??` はオリジナル版では `?` を 2 回書いただけ（＝ `A`〜`Z`）でした。`[fork]`

## 4.4 2 文字目の切り分け規則

並列表記と 2 文字目が紛らわしいため、次の規則で切り分けます。`[fork]`

> **数字（または `?`）を 2 文字目と見なすのは、その次の文字が英大文字でも `?` でも
> ない場合だけ。**

この規則により、オリジナル版で書けた並列表記の意味は 1 つも変わりません。

| 書き方 | 意味 | 理由 |
| --- | --- | --- |
| `AE` | `A`, `E` | `E` は数字でないので 2 文字目にならない |
| `A1B` | `A`, `1B` | 次が `B`（英大文字）なので `1` は 2 文字目にならない |
| `?1?` | `A`〜`Z`, `1A`〜`1Z` | 同上 |
| `1A2B` | `1A`, `2B` | 同上 |
| `A1` | `A1` | 次が行末 |
| `A10B` | `A1`, `B` | 次が `0`（数字）なので `1` は 2 文字目になる |
| `A0B1` | `A`, `0B1` | 次が `B`（英大文字）なので `0` は 2 文字目にならない |

2 文字のトラック名を並べて書くときは、間に `0` を明示してください
（`A0` と `B1` の並列は `A00B1`）。1 行に 1 トラックずつ書けばこの規則を
意識する必要はありません。`[fork]`

## 4.5 従属トラック

`1A`〜`9A` は主トラック `A` の従属トラックです。和音を書くためのものです。`[doc]`

### 同期の規則

> **従属トラックの行は、その直前に現れた同じ主トラックの行の開始ステップタイムに
> 自動的に整列されます。** `[doc]` `[obs]`

```
A  c c        ; ステップ 0 から。行の開始は 0、終了は 96
1A e          ; ステップ 0 に整列（直前の A 行の開始位置）
A  c          ; ステップ 96 から
1A e          ; ステップ 96 に整列
```

上の例で `1A` の総ステップ数は 144 になります。`[obs]`

### 使い方の指針

従属トラックでも、チャンネル指定（`Cn`）・基本音長・オクターブ・ベロシティの
設定は必要です。`[doc]`

一方、**ボリューム・エクスプレッション・ピッチベンドなど、1 チャンネルにつき
1 個の値しか持てない MIDI イベントは従属トラックに書かないでください。** `[doc]`
処理系はこれを検査しません。

### 既知の限界

繰り返し（`[ ]`）の内側の行に付けた従属トラックは、**常に 1 周目の位置にだけ
整列します。** 意図的な近似で、修正されていません。`[doc]`（`org-doc/todo.txt`）
`[11-quirks.md](11-quirks.md)` 参照。

## 4.6 出力順序

SMF に書かれるトラックの順序は、**主トラック名の順（外側）× 従属番号の順（内側）**
です。`[obs]`

```
A, 1A, 2A, …, 9A, A0, 1A0, …, A1, …, A9, …, B, 1B, …
```

実測例（`B` / `A` / `1A` / `1B` / `A0` の順に書いたソース）:

```
trk 0A  →  trk 1A  →  trk 0A0  →  trk 0B  →  trk 1B
```

**ソースに書いた順序ではありません。** `[obs]`

FORMAT 1 では、この前に第 1 トラック（テンポマップ）が置かれます。
詳細は [09-output.md](09-output.md)。

## 4.7 演奏スイッチ `=`

行頭に置く特殊な行です。`[doc]`

| 書き方 | 意味 |
| --- | --- |
| `=1` | 以降、**音符と休符のコンパイルをスキップ**する |
| `=0` | 元の演奏状態に戻る |
| `=` | `=0` と `=1` を交互に切り換える |

- 初期状態は `=0`。`[doc]`
- **行頭に置いた場合はすべてのトラックに効きます。** トラックの中（コマンド列の
  途中）に置くこともでき、その場合はそのトラックだけに効きます。`[doc]`
- 目的は「長い曲の途中まで飛ばして、途中から鳴らす」ことです。単にコメントアウト
  すると音色や音量の設定まで失われますが、`=` はそれを保ちます。`[doc]`

### スキップ中の状態変更の書き戻し

> **`=1` の区間で変更された状態は、`=0` の直後にすべて書き出されます。** `[fork]`

オリジナル版が書き戻していたのは、バンク／プログラムチェンジ・モジュレーション・
ボリューム・パンポット・エクスプレッション・チャンネルプレッシャーだけでした。
`y`（生 CC）・`BS`（ベンド）・`BR`/`D`（RPN）・`N`/`TC`/`TR`（NRPN）は捨てられ、
逆に `EX`/`EE`/`mv`/`mt` は抑止されずスキップ中の位置にそのまま出力されていました。
本フォークで全種類を書き戻すようにしています。`[fork]`

書き戻しの規則:

| 項目 | 規則 |
| --- | --- |
| 重複除去 | 「種別（CC・prog+bank・bend・cpres・RPN・NRPN・raw）」と「対象（CC 番号や RPN アドレス）」の組が同じものは上書きされ、**対象ごとの最後の値だけ**が残る |
| `EX`/`EE`/`mv`/`mt` | 重複除去せず、**書かれた順にすべて**残る |
| 1 tick あたりのバイト数 | `#pswflush` で指定した上限まで詰め、超えたら 1 tick 進める。省略時は `1562 / timebase`（1 未満なら 1） |
| トラック間の同期 | **すべてのトラックが同じステップタイムから再開します。** 書き戻しに必要な tick 数が最も多いトラックに合わせて、他のトラックも同じだけ進みます |

バイト数の計算はランニングステータスの有無を考慮します。エクスクルーシブは
ランニングステータスを打ち切ります。`[fork]`

### 既知の限界

**`=0` をはさむと `^n` が休符になります。** `^` による音長の加算は先読みで
判定され、その先読みは行をまたげますが、`=` の行に当たると音長の確定が
打ち切られ、取り残された `^` が休符として扱われます。警告は出ます。`[fork]`
（[11-quirks.md](11-quirks.md)）

## 4.8 `!` — トラックの打ち切り

そのトラックの、このコマンド以降のデータを無視します。`[doc]`
