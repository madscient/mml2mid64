# 01. 字句規則

> 完成度: 骨格＋主要な実測。`[?]` が 6 件残っています。

## 1.1 入力の形

MML ソースは行指向のテキストファイルです。処理系はバイト列として扱い、
文字列の中身は解釈せずそのまま SMF へ書き出します（[1.6](#16-文字列) 参照）。

| 項目 | 規則 | 出典 |
| --- | --- | --- |
| 改行 | LF / CRLF のどちらでもよい。生成される SMF は変わらない | `[obs]` |
| BOM | 先頭の UTF-8 BOM は読み飛ばす | `[fork]` |
| 行の長さ | 上限なし `[?]` | |
| 空ファイル | エラーにならない。トラックが 1 本も無い SMF を出力する `[?]` | |

**文字コードは処理系の関知するところではありません。** ただし1点だけ例外があり、
文字列の中でシフトJISの2バイト目が `\`（0x5C）と衝突するため、
「文字列はシフトJISか」という 1 ビットの状態を持ちます（[1.6.3](#163-マルチバイト文字の扱い)）。

## 1.2 行の前処理

各行は、トラック名やコマンドとして解釈される前に、次の加工を受けます。
**この順序は外部から観測できます**（後述の根拠を参照）。

1. **注釈の除去**（[1.7](#17-注釈)）
2. **行末 `\` による継続行の連結**（[1.3](#13-継続行)）
3. **行頭の空白・タブの除去** `[obs]`
4. **`#include` の再帰展開**（[02-directives.md](02-directives.md)）
5. **`# 行番号 "ファイル名"` マーカの解釈**（[10-cli.md](10-cli.md)）
6. **`${…}` マクロの展開** `[fork]`（[03-macros.md](03-macros.md)）

順序が観測できる根拠:

- 注釈の除去は文字列を認識する。`A C1"ab;cd" c` のトラック名は `ab;cd` になり、
  `;` 以降が落ちない `[obs]`
- 注釈の除去は**行を読んだその場**で行われる。このため `#sysexsinglequote on` は、
  `'…'` を使う行より前に書かなければならない `[fork]`
- 注釈を除いた残りが、改めて行の種別判定を受ける。`A C1 c` の次の行に
  `/* x` … `y */ d` と書くと、`d` だけが残った行がトラック名として不正だと報告される `[obs]`
- マクロ展開は行数を変えない。1 入力行は必ず 1 出力行になり、エラー報告の行番号がずれない `[fork]`

## 1.3 継続行

行末（注釈を除いた後）が `\` である行は、次の行と連結されます。`[doc]` `[obs]`

```
A C1 c\
d
```

は `A C1 cd` と同じです。連結後の行に対してトラック名の解釈が行われるため、
2 行目にトラック名を書く必要はありません。`[obs]`

エラーの行番号は、**連結後の行の先頭の行番号**で報告されます。つまり 2 行目の
記述が原因でも 1 行目として報告されます。`[doc]`

## 1.4 行の種別

行頭（空白除去後）の 1 文字で決まります。

| 行頭 | 種別 | 参照 |
| --- | --- | --- |
| （空） | 空行。何もしない | |
| `#` | 定義行 | [02](02-directives.md) |
| `$` | マクロ定義行 | [03](03-macros.md) |
| `=` | 演奏スイッチ行 | [04](04-tracks.md) |
| `A`〜`Z`, `0`〜`9`, `?` | MML 行（トラック名で始まる） | [04](04-tracks.md) |
| その他 | エラー（`track name illegal`） | `[obs]` |

`-c` オプション指定時のみ、**行頭が空白だった行は注釈行として捨てられます**
（継続行を除く）。指定しない場合は行頭空白は単に無視されるので、意味が正反対になります。`[doc]` `[obs]`

```
   A C1 c      ; -c なし → トラック A に c。-c あり → 注釈行として無視
```

## 1.5 空白と区切り

**空白・タブ・`|`（小節線）は完全に同等**で、コマンド列のどこにでも挿入できます。
音長式の途中にも入れられます。`[doc]` `[obs]`

```
A C1 l4 c4|^|4      ; c4^4 と同じ（96 ステップ）
```

トラック名とコマンド列の間には、空白またはタブが 1 個以上必要です。`[doc]`

## 1.6 数値

数値を取るコマンドの引数には、次の表記が使えます。原則としてすべての数値位置で
共通です `[fork]`（オリジナル版でもほぼ共通 `[doc]`）。

### 1.6.1 基本の表記

| 表記 | 意味 | 出典 |
| --- | --- | --- |
| `123` | 10 進数 | `[doc]` |
| `xHH` / `0xHH` | 16 進数。**ちょうど 2 桁** | `[doc]` |
| `x{…}` / `0x{…}` | 16 進数。桁数任意 | `[doc]` |
| `zN` | 変数（`N` は 0〜255） | `[doc]` |
| `C` | 現在の MIDI チャンネル番号（1〜16） | `[doc]` |
| `R` | ローランド式チャンネル番号（ch10→0, ch1〜9→1〜9, ch11〜16→10〜15） | `[doc]` |
| `&N` | 「N 分音符」の長さをステップ数として与える | `[doc]` |
| `iN` / `jN` | 半音数からピッチベンド値を算出 | `[fork]` |
| `式 + 式` / `式 - 式` | 加減算。連結できる | `[doc]` |

**16 進が 2 桁固定であることの帰結**（実装上重要）: 桁が足りない場合、
**空白を読み飛ばして次の文字を 2 桁目として消費します**。

```
A C1 vx4 c      ; v に 0x4c(=76) が渡り、'c' は音符として残らない（0 ステップ）
```

これはエラーになりません。`[obs]`

### 1.6.2 音長文脈での `%`

音長を書く位置では、先頭に `%` を付けるとステップ（クロック）数の直接指定に
なります。詳細は [05-time.md](05-time.md)。`[doc]`

### 1.6.3 マルチバイト文字の扱い

文字列の中でシフトJISの 1 バイト目に相当するバイトが現れた場合、次の 1 バイトを
無条件に読み飛ばします（`\` との衝突を避けるため）。この動作の有無は
`-m` オプションで反転します。`[doc]`

既定値はプラットフォーム依存で、Windows 版は「シフトJISである」、
UNIX 版は「シフトJISでない」と仮定します。`[doc]` `[?]`（本フォークでの既定値は要確認）

ISO-2022-JP は扱えません。`[doc]`

## 1.7 文字列

区切りは `"` です。`#sysexsinglequote on` を指定した場合のみ `'` に切り替わり、
その場合 `"` は区切りでなくなります（両方の混在は不可）。`[fork]`

| 表記 | 意味 | 出典 |
| --- | --- | --- |
| `\OOO` | 8 進数で指定した 1 バイト `[?]`（桁数の上限は要確認） | `[doc]` |
| `\xHH` | 16 進数で指定した 1 バイト `[?]`（桁数は要確認） | `[doc]` |
| `\n` `\t` `\b` `\r` `\f` `\a` `\v` | C 言語と同じ | `[doc]` |
| `\e` | `\033`（ESC） | `[doc]` |
| `\` + 上記以外 | その文字そのもの | `[doc]` |
| `"…"+"…"` | 連結 | `[doc]` |

規則:

- **生の改行は入れられません。** `\n` と書きます。`[doc]`
- **閉じ忘れはエラー**です。`[doc]`
- 文字列の中では**マクロ展開が行われません**。`[doc]`
- 文字列の中では `[` `]` があってもループになりません。`[doc]`
- 文字列の中の `;` は注釈になりません。`[obs]`
- 文字列の中の `#1` は引数展開されません。`[fork]`
- 連結は `#` で始まる定義行**以外**のすべての文字列で使えます。`[doc]`

文字列の中身は 1 バイトも変換されずに SMF へ書き出されます。したがって
**ソースの文字コードを変えると生成される SMF が変わります。**

## 1.8 注釈

| 表記 | 範囲 | 出典 |
| --- | --- | --- |
| `;` | 行末まで | `[doc]` |
| `/*` … `*/` | 閉じるまで。行をまたげる。**入れ子にできない** | `[doc]` `[obs]` |

- 閉じる `*/` が無いとエラー（`comment not closed`）。`-c` 指定時はエラーになりません。`[doc]` `[obs]`
- `/*` は行の途中にも書けます。`[obs]`（`org-doc/command.txt` は「行頭に置く」と
  書いていますが、実装は行中でも受け付けます。[11-quirks.md](11-quirks.md) 参照）
- 注釈を除いた残りの行が空でなければ、通常どおり解釈されます。`[obs]`
