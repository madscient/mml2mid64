# 05. 時間モデル

> 完成度: 音長式とゲートタイム（丸め・下限を含む）を実測で確定。`[?]` が 2 件。

## 5.1 ステップと tick

時間の単位は**ステップ**で、**SMF の tick と 1:1 で対応します。** タイムベース
（`#timebase`、既定 48）が 4 分音符あたりのステップ数で、そのまま SMF ヘッダの
division に書かれます。`[obs]`

各トラックは独立にステップタイム（トラック先頭からの累積ステップ数）を持ち、
音符・休符がこれを進めます。

## 5.2 音長式

音長を書ける位置（音符・休符・`l` コマンドの引数など）では、次の形の式を書けます。

```
音長式 ::= [ '%' ] 数値? ('.')* ( ('^' | '-') 音長式片 )*
```

| 要素 | 意味 | 出典 |
| --- | --- | --- |
| 数値 | **n 分音符**。`4` なら 4 分音符 = timebase ステップ | `[doc]` |
| `%` + 数値 | **ステップ（クロック）数の直接指定**。`c4` ≡ `c%48`（timebase 48 のとき） | `[doc]` `[obs]` |
| 数値の省略 | `l` コマンドの現在値を採用。`%` を付けた場合も同じ | `[doc]` `[obs]` |
| `.` | 付点。**複数付けられます** | `[doc]` `[obs]` |
| `^` + 音長 | 加算。いくつでも書けます | `[doc]` `[obs]` |
| `-` + 音長 | 減算。いくつでも書けます | `[doc]` `[obs]` |

音長の上限はありません（SMF のデルタタイムは可変長で書かれるため）。`[doc]`

### 実測

timebase 48 のとき:

| 記述 | ステップ数 | 内訳 |
| --- | --- | --- |
| `c4` | 48 | |
| `c4.` | 72 | 48 + 24 |
| `c4..` | 84 | 48 + 24 + 12 |
| `c8^16` | 36 | 24 + 12 |
| `c8-32` | 18 | 24 − 6 |
| `c%12` | 12 | |
| `l4 c%` | 48 | `l` の値 |
| `l2 c%-8` | 72 | 96 − 24 |

### 加算・減算は後ろから累算される

`^` と `-` が連続する場合、**後ろから順に畳み込まれます。** `[doc]` `[obs]`

```
c8-32-48     ; 22 = 24 − (6 − 4)     ← -32 と -48 が先に「6 − 4 = 2」になる
c8-32^48     ; 14 = 24 − (6 + 4)
```

`c8-32-48` を「24 から 6 を引き、さらに 4 を引く」と読むのは誤りです。

### `-` の曖昧性

`-` は音符のフラット記号と同じ文字です。**音符の直後の `-` はフラット**として
解釈されます。`[doc]`

| 記述 | 解釈 |
| --- | --- |
| `c-32` | c のフラット、音長 32 分音符 |
| `c8-32` | c、音長は 8 分音符 − 32 分音符 |
| `c-8-32` | c のフラット、音長は 8 分音符 − 32 分音符 |
| `c--8` | c のダブルフラット、音長 8 分音符（`#bc525` なしの場合） |
| `c-%-8` | c のフラット、音長は `l` の値 − 8 分音符 |

「所定の長さより 8 分音符だけ短い音」を書きたい場合は、`c%-8` のように
`%` を挟んでください。`c-8` と書くとフラットになります。`[doc]`

## 5.3 音長 0

音長を 0 にすると、**ノートオンだけを生成してステップを進めません。**
ノートオフも行われません。1 トラックに和音を書くために使います。`[doc]`

```
A C1 c0e0g4      ; c, e, g が同時に発音し、g4 の終わりで 3 音まとめてノートオフ
```

`l0` / `l%0` も指定できます。`[doc]`

**休符の `r0` だけは例外**で、オリジナル版では常に無視されます。`[doc]`
本フォークでは、発音中の音がある場合に限り「まとめてノートオフする」意味を
持ちます（[06-notes.md](06-notes.md)）。`[fork]`

## 5.4 ゲートタイム

ノートオンからノートオフまでの長さです。音長そのものではありません。

| コマンド | 意味 | 初期値 | 出典 |
| --- | --- | --- | --- |
| `Qn` | 発音時間を **n/8** にする（割合指定） | 8 | `[doc]` |
| `qn1,n2` | ノートオフを **n1 ステップ早める**。`n2` は**最低発音長**（`n1` より優先） | n1=1, n2=0 | `[doc]` |
| 音符の第 2 引数 | その音符だけの `n1`（`c4,100,10` の `10`） | — | `[obs]` |

### 計算の順序

```
g = round(音長 × Q / 8)          ← 四捨五入（.5 は切り上げ）
if Q ≠ 0 and g < 1 : g = 1       ← Q が 0 でなければ 1 を下回らない
g = g − q₁
if g < q₂ : g = q₂
if g < 0  : g = 0                ← 下限は 0
ゲートタイム = g
```

`[obs]`

**除算は四捨五入です**（切り捨てではありません）。`[obs]`

| 記述（`q0`） | 音長 × Q / 8 | ゲート |
| --- | --- | --- |
| `Q1 c%1` | 0.125 | 1（下限） |
| `Q1 c%3` | 0.375 | 1（下限） |
| `Q1 c%4` | 0.5 | 1 |
| `Q1 c%12` | 1.5 | 2 |
| `Q1 c%20` | 2.5 | 3 |
| `Q3 c%50` | 18.75 | 19 |
| `Q7 c%50` | 43.75 | 44 |
| `Q0 c4` | 0 | 0（`Q0` には下限が効かない） |

`q` による短縮が音長を超えても負にはならず 0 で止まります
（`q50 c4` / `q100 c4` のゲートは 0）。`[obs]`

### `q` との組み合わせの実測（timebase 48）

| 記述 | 音長 | ゲート | 内訳 |
| --- | --- | --- | --- |
| `c4` | 48 | 47 | 48 − 1（q の初期値） |
| `q3 c4` | 48 | 45 | 48 − 3 |
| `q0 c4` | 48 | 48 | |
| `q500,2 c4` | 48 | 2 | 最低発音長 2 が優先 |
| `Q2 c2` | 96 | 23 | 96×2/8 = 24、−1 |
| `Q2 q3 c2` | 96 | 21 | 24 − 3 |
| `c4,100,10,40` | 48 | 38 | 48 − 10（第 2 引数） |

**音符の第 2 引数は「ゲートタイム」と呼ばれていますが、実際には
`q` の第 1 引数と同じ「短縮量」です。** `[obs]`（`org-doc/mml2mid.txt` の
記述は「ゲートタイム 10」とだけ書いており誤解を招きます。[11-quirks.md](11-quirks.md)）

### 負の `q`

`q-n` はノートオフを**音長より n ステップ遅らせます**。レガート／スラーの
模倣に使えます。`[doc]`

```
A C1 q-4 c4 d4
```

実測: c のノートオン → 48 ステップ後に d のノートオン → その 4 ステップ後に
c のノートオフ → 44 ステップ後に d のノートオフ。`[obs]`

Ver 5.0 以前は `q-n` が「ノートオン後 n クロックでノートオフ」の意味でした。
現在の版で同じことをするには `q500,2` のように第 1 引数を大きく、第 2 引数
（最低発音長）を目的の値にします。`[doc]`

### 休符とゲートタイム

**休符はゲートタイムを持ちません。** 休符の直前まで発音していた音は、
休符の長さを**丸ごと消費した位置**でノートオフされます。`[obs]`

```
A C1 c&r2        ; ノートオフはステップ 144（= 48 + 96）。q による短縮は効かない
```

したがって `c&r2` と `c^2` は完全には同じになりません。`c^2` はゲートタイム 143
（144 − 1）です。`org-doc/mml2mid.txt` が「ほぼ同じ意味」と書いているのはこの差です。
`[obs]`

## 5.5 ノートオフの表現

**キーオフベロシティが 0 かどうかで、出力される MIDI メッセージの形が変わります。**
`[obs]`

| キーオフベロシティ | 出力 | 例 |
| --- | --- | --- |
| 0（既定） | ノートオン、ベロシティ 0 | `90 3C 00`（ランニングステータス時は `3C 00`） |
| 0 以外 | ノートオフ `0x8n` | `80 3C 28` |

キーオフベロシティは `wn` コマンド（初期値 0）または音符の第 3 引数で指定します。`[doc]`

これは出力バイト列に直結するため、再実装では必ず同じにしてください。

## 5.6 複数音のノートオフ順序

同時にノートオフされる音が複数ある場合の順序です。`[obs]`

| 状況 | 順序 |
| --- | --- |
| 音長を持つ音符が、保留中の音を巻き込んで終わる（`c0e0g4`） | **その音符が先**、続いて保留中の音をキーオンした順（g → c → e） |
| 休符が保留中の音をまとめて閉じる（`c0e0g0 r4`） | キーオンした順（c → e → g） |
