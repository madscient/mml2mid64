# 06. 音符と休符

> 完成度: 音高・ベロシティ・クランプを実測で確定。連結（`&` / `~`）は記述済み・一部未実測。`[?]` が 4 件。

## 6.1 音符の文法

```
音符 ::= 音名 臨時記号* 音長式? ( ',' ベロシティ ( ',' 短縮量 ( ',' キーオフベロシティ )? )? )?
```

| 音名 | 対応 |
| --- | --- |
| `c` `d` `e` `f` `g` `a` `b` | ド レ ミ ファ ソ ラ シ |
| `h` | `#german` 指定時のみ有効で「シ」。`b` は「シのフラット」になる |

**`o4` の `c` が MIDI ノートナンバー 60 です。** `[doc]` `[obs]`

実測（`o4`、timebase 48）: `c`=60, `d`=62, `e`=64, `f`=65, `g`=67, `a`=69, `b`=71

## 6.2 臨時記号

音長指定の**前**に置きます。`[doc]`

| 記号 | 意味 | 実測（`o4 c` 基準） |
| --- | --- | --- |
| `+` | シャープ | `c+` = 61 |
| `-` | フラット | `c-` = 59 |
| `++` | ダブルシャープ | `c++` = 62 |
| `--` | ダブルフラット | `c--` = 58 |
| `*` | ナチュラル（調号を打ち消す） | |

- 3 つ以上は書けません。`[doc]`
- `#bc525` 指定時は `--` の意味が変わります（[02-directives.md](02-directives.md)）。`[doc]`
- **明示的な `+` / `-` は、調号ではなく本来の音高からの半音上下です。** `[doc]` `[obs]`
  `KJg`（ト長調）でも `f-` は `f` の半音下（= `e`）であり、`f♯` の半音下ではありません。

## 6.3 オクターブ

| コマンド | 意味 | 初期値 | 出典 |
| --- | --- | --- | --- |
| `on` | オクターブを設定 | 4 | `[doc]` |
| `o+n` / `o-n` | 相対指定 | | `[doc]` |
| `>` | 1 つ上げる（`o+1`） | | `[doc]` |
| `<` | 1 つ下げる（`o-1`） | | `[doc]` |

`>` と `<` の効果は `#swap<>` またはコマンドラインの `-x` で入れ替わります。`[doc]`

実測: `o4 c`=60, `>c`=72, `<<c`=48, `o6 c`=84, `o-1 c`=72 `[obs]`

## 6.4 調号

| コマンド | 意味 |
| --- | --- |
| `KJ<音名>` | 長調の調号（Key maJor）。`KJg` = ト長調 |
| `KI<音名>` | 短調の調号（Key mInor）。`KIe` = ホ短調（= `KJg`） |

- 音名の後に `+` / `-` を 2 つまで繋げられます（`KJe-` = 変ホ長調）。`[doc]`
- **解除は `KJc`（ハ長調）または `KIa`（イ短調）**です。`[doc]`
- `#german` 指定時、`KJb` / `KIb` の後ろには `+` も `-` も付けられません。`[doc]`
- `#german` 指定時、調号は `h` には効きますが `b` には効きません。`b` は常に
  `h-` と同じ音です。`[doc]`
- 1 文字目が `K` で 2 文字目が大文字の `J` / `I` であることによって、キーオン
  コマンド `K` と区別されます。`[doc]`

実測（`KJg`）: `f`=66（F♯）, `f+`=66, `f-`=64, `f*`=65 `[obs]`

## 6.5 移調

| コマンド | 意味 | 初期値 | 範囲 | 出典 |
| --- | --- | --- | --- | --- |
| `_n` | そのトラックの以降を n 半音移調 | 0 | −99〜99 | `[doc]` |
| `__n` | 相対移調（`_n` の値を n 変化） | | | `[doc]` |
| `*n` | `__n` と同じ。`#bc525` 指定時のみ | | | `[doc]` |

コマンドラインの `-tn` は全体を移調しますが、**`RT` が指定されたトラックは
移調しません。** `[doc]`

実測: `c _2 c __1 c` → 60, 62, 63 `[obs]`

## 6.6 `Jn` — 音階の固定

音階を番号で指定し、**このコマンド以降の音名を無視します**（強制的に音階が n に
なります）。`J0` で解除。初期値 0。ドラムパート向けです。`[doc]`

実測: `J36 c e` → どちらも 36、`J0 c` → 60 `[obs]`

## 6.6.1 ノートナンバーのクランプ

> **オクターブ・臨時記号・移調・`J` をすべて適用した結果は 0〜127 にクランプ
> されます。エラーにはなりません。** `[obs]`

| 記述 | 計算値 | 出力 |
| --- | --- | --- |
| `o0 _-20 c` | 12 − 20 = −8 | 0 |
| `o10 b++` | 131 + 2 = 133 | 127 |
| `J200 c` | 200 | 127 |

## 6.7 休符 `r`

音長指定は音符と同じです。`[doc]`

- **発音中の音は、休符の長さを消費しきった位置でノートオフされます。**
  ゲートタイムの短縮は効きません（[05-time.md](05-time.md) 5.4）。`[obs]`
- `r0` はオリジナル版では常に無視されます。`[doc]`
  本フォークでは、発音中の音がある場合に限り「まとめてノートオフする（ステップは
  進めない）」意味になります。発音中の音が無ければ従来どおり無視されます。`[fork]`

## 6.8 ベロシティ

| コマンド | 意味 | 初期値 | 出典 |
| --- | --- | --- | --- |
| `kn` | ベロシティを設定 | 100 | `[doc]` |
| `k+n` / `k-n` | 相対指定。n を省略すると 1 | | `[doc]` |
| `(n` | n 下げる。n 省略時は `V` の値 | | `[doc]` |
| `)n` | n 上げる。n 省略時は `V` の値 | | `[doc]` |
| `Vn` | `(` / `)` の n 省略時の値 | 4 | `[doc]` |
| 音符の第 1 引数 | その音符だけのベロシティ（`c16,100`）。`+`/`-` で `k` からの相対も可 | | `[doc]` |

`(` と `)` の効果は `#swap()` またはコマンドラインの `-v` で入れ替わります。`[doc]`

`(n` は `k-n` と似ていますが、次の違いがあります。`[doc]`

- `(n` では第 2・第 3 引数を指定できません。直前の `k` の第 2・3 引数が
  引き続き有効です。
- `k-` は n を省略すると 1、`(` は n を省略すると `V` の値です。

実測: `k100 c`=100, `k+10 c`=110, `k-20 c`=90, `V5 (c`=85, `)c`=90 `[obs]`

### 段階的な変化 `kn1,n2,n3`

| 引数 | 意味 | 初期値 |
| --- | --- | --- |
| n1 | ベロシティ（相対指定可） | |
| n2 | **キーオンごとの変化量**（−127〜127） | 0 |
| n3 | 0 または 127 を越えたときの処理。1 で**反射**する | 0 |

> **変化はキーオンの前に適用されます。最初の音符から n2 が加算されます。** `[obs]`

実測 `k64,10 cccc` → 74, 84, 94, 104（64 ではなく 74 から始まる）`[obs]`

`org-doc/mml2mid.txt` は「k64 からベロシティが 10 ずつ増加」と書いていますが、
実際の最初の音は 74 です。[11-quirks.md](11-quirks.md) 参照。

n3 = 0 のときは端で停止、n3 = 1 のときは反射します。解除するには新たに `k` を
送ります。値を変えたくない場合は `k+0` と書きます。`[doc]`

`pn1,n2,n3`（パンポット）も同じ第 2・第 3 引数を取ります。`[doc]`

### ランダムベロシティ `krn1,n2`

現在のベロシティ値から ±n1 の範囲でランダムに変化させます。`kr0` で解除。`[doc]`

| n2 | 分布 |
| --- | --- |
| 1（省略時） | 現在値に近いほど生起確率が高い |
| 2 | 現在値から離れるにつれ直線的に確率が下がる |
| 3 以上 | 離れた値の確率が高くなる。大きいほど顕著 |

> **⚠ 出力は決定的ではありません。** 同じ入力を 2 回コンパイルすると異なる
> ベロシティ値が出ます。`[obs]`
>
> ```
> kr10 cccc  →  1 回目: 98, 98, 100, 99 ／ 2 回目: 104, 98, 99, 98
> ```
>
> **`kr` を使う MML では、バイト一致による適合性の検証ができません。**
> 再実装では、乱数列を一致させることは（乱数源が処理系依存のため）不可能です。
> 検証用のコーパスからは `kr` を使う MML を除外してください。
> 乱数の分布形状を仕様として満たせば十分とします。`[?]`

`kr1`（または `kr n,0`）はオリジナル版でゼロ除算を起こします。`[fork]` で修正済み。

## 6.10 和音と連結

### 音長 0 による和音（オリジナル版から）

```
A C1 c0e0g4.
```

音長 0 の音符はノートオンだけを生成してステップを進めません。`g4.` の音長が
終わった時点で 3 音まとめてノートオフされます。`[doc]`

### `&` — ノートオフの抑制（既定）

`&` は**直前の音をキーオフしません。** 音符または休符の直後でないと意味を
持ちません。`[doc]`

**`&` は音長を合算しません。** 各音符は自分の音長分ステップを進めます。`[obs]`

```
A C1 c&e&g4      ; c(48) → e(48) → g(48)。合計 144 ステップ
                 ; ノートオフは g の終わりに 3 音まとめて
```

用途:

| 記述 | 効果 |
| --- | --- |
| `c&r2` | タイに近い（ただしゲートタイムの扱いが `c^2` と異なる） |
| `c&e&g` | 同時発音の和音 |
| `c64&e64&g8-32` | タイミングをずらした和音 |
| `v100 c4& v80 r2` | 発音したままボリュームを変える |

### `#ampasandtie on` — `&` をタイ／スラーにする `[fork]`

| 書き方 | `off`（既定） | `on` |
| --- | --- | --- |
| `c&e&g4` | 3 音を重ねて和音 | `c`→`e`→`g` をレガートで繋ぐ |
| `c4&c4` | `c` を 2 回重ねて発音 | 音長を合算した 1 音（タイ） |

`on` のときの規則:

- **前後が同じ音高**なら音長を合算します。ノートオンは 1 回だけです。
- **前後が異なる音高**なら、チェーンの**先頭ノートのノートオフの直前**に
  レガート・オン（CC#68 = 127）を、**末尾ノートのノートオフの直前**に
  レガート・オフ（CC#68 = 0）を挿入します。途中のノートは通常どおり
  個別にノートオン・ノートオフします。
- **休符が挟まっている場合**、休符は「ノートオフを伴わないステップ消費」として
  扱われます。音高の比較は休符を除いた実音符同士で行います。
  `c&r&c` は同音として合算、`c&r&d` は異音としてレガートの対象。
  チェーンの先頭が休符なら、最初の実音符の発音開始が遅れるだけです。
- チェーンの途中に `K` または `A` が現れる書き方は**コンパイルエラー**です。
- レガートの対象になる先頭・末尾のノートに負のローカルゲートタイム（`,,-n`）を
  指定するのも**コンパイルエラー**です。

例: `c&d&e&f&f&g&a` は `f&f` が合算されて c,d,e,f,g,a の 6 音のスラーになります。

### `~` — 自動ポルタメント `[fork]`

音名を `~` で繋ぐと、上記のタイ／スラー連結に加えて、チェーンの境界に
ポルタメント・オン／オフ（CC#65）を挿入します。位置はレガートと同じです。

- **`#ampasandtie` の on/off に関わらず常に有効**です。
- `&` と `~` は同じチェーンで混在できます（`c&d~e&f`）。チェーンの中に `~` が
  1 個でもあれば、チェーン全体にポルタメントが付きます。
- 音高の合算・休符の扱い・`K`/`A` 禁止・負のローカルゲートタイム禁止は
  `&` チェーンと同じです。

**曖昧性の解決:** `~` は元々 `BSn`（ベンド）の省略形です。
**`~` の直後が音名として解釈できない場合（数字や `+`/`-` など）は、従来どおり
`BSn` として処理されます。** 判定は `~` の次の 1 文字まで見て行われるため、
既存の `~n` の使い方はすべてこれまでどおり通ります（`c~64` は「note c」+「BS64」）。

### `` `<音名> `` — 個別のノートオフ `[fork]`

| 書き方 | 動作 |
| --- | --- |
| `` `<音名> `` | 発音中の和音のうち、一致する音を **1 つだけ**ノートオフ |
| `` `<音名><音長> `` | 指定した音長分ステップを進めてから、その音をノートオフ |
| `` `r<音長> `` | ステップを進めるだけ。**ノートオフは一切しない** |
| `r0` | 発音中の和音をまとめてノートオフ（ステップは進めない） |

```
A C1 @0 o4 l4
A c0e0g0          ; c,e,g を同時に発音
A `e              ; e だけ先にノートオフ（c,g はまだ鳴っている）
A `r4             ; 4 分音符分だけ経過（誰もノートオフしない）
A `c `g           ; 残りを個別にノートオフ
```

- 音長を省略した場合は `l` コマンドの現在値が使われます（「即座にノートオフ」には
  なりません）。音名の前後の記法（臨時記号・オクターブ・`K`/`J` による強制転調）は
  通常の音符と同じように働きます。
- カンマ区切りのベロシティ・ゲートタイム・キーオフベロシティは**指定できません**。
- 一致する音が無い場合はエラー
  （`` backquote note off '`?' has no matching sounding note ``）。
- **ただし発音中の音が 1 つも無い場合**は、エラーにする代わりに **CC#84
  （Portamento Control）**でその音名をポルタメントのソースノートとして指定します。
  ノートオンは生成しません。この用途では音長やカンマ引数を付けられません。
  ```
  A `c d      ; CC84(60) を送ってから d を鳴らす（d は c からポルタメント）
  ```

**既知の限界:** トラック終端で閉じられていない発音中の音は、何もノートオフされません。
`[fork]`

## 6.11 `K` — 任意タイミングのキーオン

このコマンドの直後に書いた音名でキーオンします。`[doc]`

- 臨時記号・調号が有効です。
- `,` で区切ってベロシティを指定できます。省略時は `k` の値。
- 音長指定は `rn&` で行います。
- **自動的にキーオフしません。** `Kc,0` のようにベロシティ 0 の音符を書いて
  キーオフする必要があります。

```
Kc,100 r8& e16r16g8 r8 Kc,0
```

複雑な音符の組み合わせは、複数トラックまたは従属トラックで書くことが推奨されます。`[doc]`

## 6.12 `A` — ポリフォニックキープレッシャー

直後に書いた音名の、既に発音中の音に対してポリフォニックキープレッシャーを
与えます。指定の仕方は `K` と全く同じで、`,` でベロシティ（プレッシャーの強さ）を
指定できます。省略時は `k` の値。`[doc]`

```
c4& Ac,50 r8
```
