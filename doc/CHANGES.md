# オリジナル版との差分

本リポジトリは **mml2mid Version 5.30b**（門田暁人・藤井秀樹（MKR）・黒田久泰・
新出尚之 の各氏による作品）のフォークです。ここでは、**オリジナル版を使っていた方
から見て何が変わったか**をまとめます。

開発側の視点での時系列の変更履歴は [STATUS.md](STATUS.md) を参照してください。
オリジナル配布物のドキュメント一式は [`org-doc/`](../org-doc/) にそのまま残して
あります。

## いちばん大事なこと

**既存のMMLは、書き直さずにそのまま使えます。**
MMLの拡張（`P` / `X` の引数、トラック名の2文字目）はいずれも**書き足せるように
なっただけ**で、従来どおりの書き方をしている限り解釈は変わりません。同梱サンプル
32曲のうち28曲が、オリジナル版が生成した `.mid` とバイト単位で完全一致することを
確認しています（残り4曲の理由は [test/README.md](../test/README.md) に記載。いずれも
本フォークでの退行ではありません）。

ただし1件だけ、**生成されるMIDIが変わりうる不具合修正**があります。同じ行で主
トラックの指定より後ろに従属トラックを並べて書いた場合（`A1A` など）、オリジナル版
はその従属トラックを黙って捨てていました。本フォークでは正しく出力します。詳しくは
「[不具合修正によって変わる挙動](#不具合修正によって変わる挙動)」を参照してください。

## MMLの拡張

### `P` / `X` コマンド — ペダル類のオン・オフ

オリジナル版の `P` / `X` はダンパー・ペダル（コントロールチェンジ64番）専用でした。
本フォークでは 0〜4 の引数を取れるようになり、他のペダル系コントロールチェンジも
扱えます。

| コマンド | 動作 | コントロールチェンジ |
| --- | --- | --- |
| `P0` / `X0` | ダンパー・ペダル　オン / オフ | 64 |
| `P1` / `X1` | ポルタメント　　　オン / オフ | 65 |
| `P2` / `X2` | ソステヌート　　　オン / オフ | 66 |
| `P3` / `X3` | ソフト・ペダル　　オン / オフ | 67 |
| `P4` / `X4` | レガート　　　　　オン / オフ | 68 |

- 引数を省略した `P` / `X` は **`P0` / `X0` と同じ**です。つまりオリジナル版と同じ
  ダンパー・ペダルのオン・オフになります。
- オンは値127、オフは値0を送出します。
- 引数は他のコマンドと同じ書き方が使えます。変数（`Pz3`）、16進（`P0x2`）、
  加減算（`P1+1`）など。
- 0〜4 以外を指定するとコンパイルエラーになります。

```
A C1 @0  o4 l4
        P  cdef X        ; ダンパー・ペダル（従来どおりの書き方）
        P0 cdef X0       ; 同上（明示的に書いた場合）
        P4 cdef X4       ; レガート・オン〜オフ
```

なお、ペダル系のコントロールチェンジは重複除去（同じ値の連続を省く最適化）の対象外
です。書いた回数だけそのままMIDIに出力されます。

### トラック名 — 2文字目に数字を書けるようになりました

オリジナル版のトラック名は `A`〜`Z` の1文字だけで、主トラックは26本が上限でした。
本フォークでは2文字目に数字を付けられます。

| 書き方 | 意味 |
| --- | --- |
| `A` | 従来どおりの1文字のトラック名 |
| `A0` 〜 `A9` | 新しい2文字のトラック名。`A` とは**別のトラック** |
| `1A0` | トラック `A0` の従属トラック1 |

主トラックは 26 + 26×10 = **286本**まで書けます。従属トラックも従来どおり
`1`〜`9` を頭に付けられるので、トラックは最大 2860 本になります。

```
A  C1 o4 l4 cdef      ; 従来どおりのトラック A
A0 C2 o4 l4 efga      ; トラック A0（A とは別のトラック）
A1 C3 o4 l4 gab>c     ; トラック A1
1A0 C4 o5 l4 c        ; A0 の従属トラック1
```

トラック名の並び順（SMFに書かれる順番）は `A`, `A0`, `A1`, …, `A9`, `B`, `B0`, …
です。

**ワイルドカード `?` は桁ごとに展開されます。**

| 書き方 | 意味 |
| --- | --- |
| `?` | `A`〜`Z`（従来どおり。1文字のトラック名だけ） |
| `A?` | `A0`〜`A9` |
| `?0` | `A0`〜`Z0` |
| `??` | `A0`〜`Z9`（2文字のトラック名すべて） |
| `1??` | `1A0`〜`1Z9` |

2文字目の `?` は `0`〜`9` を表すので、`A?` に1文字のトラック名 `A` は**含まれません**。

**並列表記との関係。** オリジナル版から、トラック名は `AE`（＝ `A` と `E`）のように
並べて書けます。2文字目を足すとこれと紛らわしくなるため、**2文字目と見なすのは、
その次の文字が英大文字でも `?` でもない場合だけ**という規則にしました。これにより、
オリジナル版で書けた並列表記の意味は一つも変わりません。

| 書き方 | 意味 | 備考 |
| --- | --- | --- |
| `AE` | `A`, `E` | 従来どおり（`E` は数字でないので2文字目にならない） |
| `A1B` | `A`, `1B` | 従来どおり。`A1`, `B` にはならない |
| `?1?` | `A`〜`Z`, `1A`〜`1Z` | 従来どおり。`?1`, `?` にはならない |
| `1A2B` | `1A`, `2B` | 従来どおり |
| `A1` | `A1` | 次が行末なので2文字目になる |
| `A10B` | `A1`, `B` | 次が `0`（数字）なので `1` は2文字目になる |
| `A0B1` | `A`, `0B1` | 次が `B`（英大文字）なので `0` は2文字目にならない |

つまり、2文字のトラック名を並べて書くときは間に `0` を明示してください
（`A0` と `B1` の並列は `A00B1`）。1行に1トラックずつ書けば、この規則を意識する
必要はありません。

なお `??` は、オリジナル版では `?` を2回書いただけ（＝ `A`〜`Z`）でしたが、
本フォークでは2文字のトラック名すべてを表します。実用上、`??` を書く意味は
オリジナル版にはありませんでした。

### 出力できるトラック数の上限

オリジナル版の上限は64本（`too many tracks` エラー）で、しかもSMFヘッダのトラック数
を1バイトでしか書いていませんでした。本フォークでは16ビットで正しく書き出すように
し、上限をトラック名の組み合わせ数（2860本＋テンポマップの1本）まで引き上げました。
SMFの仕様上の上限は65535本です。

## エラーメッセージの追加

オリジナル版には無かったエラーメッセージが2つあります。どちらも、オリジナル版では
エラーにならずに壊れた動作をしていたケースを、正しく検出するようにしたものです。

| メッセージ | 意味 |
| --- | --- |
| `pedal 'P?' or 'X?' is wrong` | `P` / `X` の引数が 0〜4 の範囲外です |
| `exclusive data too long` | `EX` / `EE` のデータが長すぎます（後述） |

## 不具合修正によって変わる挙動

オリジナル版のバグを直した結果、ユーザーから見て動作が変わる箇所です。

- **同じ行で主トラックより後ろに書いた従属トラックが無視されなくなりました。**
  これだけは**生成されるMIDIが変わります**。オリジナル版は、どのトラックが存在
  するかを調べる処理が主トラックを見つけた時点で行の残りを読むのをやめていたため、
  `A1A ...`（トラック `A` と、その従属トラック `1A` に同じMMLを書く指定）と書くと
  `1A` が黙って捨てられていました。同じ行でも主トラックより前に書いた場合
  （`1AA ...`）は正しく動いていたので、一貫していませんでした。現在はどちらでも
  `1A` が出力されます。ワイルドカードを使った `0?2?` のような指定でも同じ問題が
  ありました。

- **`EX` / `EE` が長すぎる場合。** オリジナル版は境界チェックをしておらず、長い
  エクスクルーシブを書くとスタックを破壊して異常終了（あるいは無関係な誤動作）を
  起こしていました。現在は `exclusive data too long` エラーで正しく停止します。
- **`kr1`（または `kr n,0`）でクラッシュしなくなりました。** オリジナル版はゼロ除算で
  異常終了していました。
- **`S` コマンドを多用したトラックでクラッシュしなくなりました。** 進捗表示用の
  8KB固定バッファが溢れていたものです。
- **`#title` / `#copyright` が256バイトの場合。** オリジナル版は長さ0として書き出す
  ため壊れたメタイベントになっていました。現在は255バイトまでを上限としてエラーに
  します。
- **パイプからの入力が動くようになりました。** `cat foo.mml | mml2mid - foo.mid`
  のような使い方が、オリジナル版では空入力になっていました。

最初の1件を除き、正常なMMLをコンパイルした場合の出力には影響しません。

## 対応環境とビルド方法

| 項目 | オリジナル版 | 本フォーク |
| --- | --- | --- |
| 対応環境 | MS-DOS / Win16 / Win32 / UNIX（32bit） | Windows / Linux / macOS（**64bit**） |
| ビルド | 環境ごとの `makefile.bcc` / `.egc` / `.lcc` を選択 | `CMakeLists.txt` または `src/makefile` の一本化。設定用スイッチ不要 |
| 同梱バイナリ | DOS版・Win32版の `.exe` を同梱 | 同梱せず（ソースからビルド） |

- Win64では、オリジナル版のファイル位置計算が `long`（32bit）で切り詰められており、
  そもそも正しく動作しませんでした。これが64bit化の主眼です。
- MS-DOS版・Win16 GUI版のコードは削除しました。これらの環境向けにビルドすることは
  できません。
- 詳細は [BUILD.md](../BUILD.md) を参照してください。

## 文字コード

オリジナル配布物は全体がEUC-JPでした。本フォークではソースとドキュメントをUTF-8に
変換していますが、**コンパイラへの入力データは元のまま**です。

| 対象 | 文字コード |
| --- | --- |
| ドキュメント（`org-doc/*.txt`、`doc/*.md`、`src/mml2mid.1`） | UTF-8 |
| `org-doc/tr-rack.mml` | **EUC-JP のまま** |
| `org-doc/mml2mid.def` | 変更なし（VZエディタ用、バイナリを含む） |

`.mml` はドキュメントではなくコンパイラへの入力データです。mml2mid は文字列中の
バイトをそのままSMFのメタイベント（曲名・トラック名など）へ書き出すため、`.mml` の
文字コードを変えると**生成されるMIDIの中身が変わります**。自分のMMLで日本語を使う
場合は、従来どおり `-m` オプション（文字列中をShift-JISとみなす）で使い分けてください。

## 配布物の構成

### サンプル曲（`sample/`）は同梱していません

オリジナル配布物に含まれていたサンプル曲は、**本フォークでは再配布していません。**
各曲の著作権はそれぞれの作曲者に帰属する第三者の著作物で、自由利用が明示されて
いるのは門田氏作の曲のみだからです。

回帰テストを実行する場合は、
[オリジナル配布物](https://www.vector.co.jp/soft/dl/unix/art/se102432.html)の
`sample/` ディレクトリをツリー直下にコピーしてください。無い場合はテストが無効に
なるだけで、ビルドは正常に行えます。詳細は
[test/README.md](../test/README.md) を参照してください。

### ドキュメントの配置

オリジナル版の `doc/` は `org-doc/` にリネームし、本フォークで書いたドキュメントを
新しい `doc/` に置いています。

| パス | 内容 |
| --- | --- |
| `org-doc/` | **オリジナル配布物のドキュメント**（MMLリファレンス、テクニック集など。内容はそのまま） |
| `doc/` | 本フォークのドキュメント（このファイルと [STATUS.md](STATUS.md)） |
| `test/` | 回帰テスト用のベースライン・トラック名テスト・スクリプト（本フォークで追加） |
| `cmake/` | ctest から呼ばれるテスト実行スクリプト（本フォークで追加） |

`org-doc/` 内の記述は**オリジナル版時点のもの**です。`org-doc/mml2mid.txt` や
`org-doc/command.txt` の `P` / `X` の説明は引数なしのまま、`org-doc/mml2mid.txt`
「3.4.1 トラック名」も1文字のトラック名のままなので、上記
「[MMLの拡張](#mmlの拡張)」で読み替えてください。ルートの
[readme.txt](../readme.txt) と `org-doc/chnglog.txt` も同様に、オリジナル配布物の
内容をそのまま残しています。
